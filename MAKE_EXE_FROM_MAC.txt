================================================================================
  BUILD FROM A MAC (no Windows PC needed)
================================================================================

You cannot create QuirkCode.exe on a Mac itself.
Use free GitHub Actions (a Windows cloud machine builds it for you).

STEPS
-----
1. Create a free GitHub account: https://github.com/signup

2. Create a new repo: https://github.com/new
   - Name: QuirkCode (or anything)
   - Public
   - Do NOT add README
   - Click Create repository

3. GitHub will show commands. On your Mac open Terminal and run
   (replace YOUR_USER with your GitHub username):

     cd /Users/premmehtaprem/AutoEvent
     git remote add origin https://github.com/YOUR_USER/QuirkCode.git
     git push -u origin main

   Sign in when asked.

4. Open the repo in the browser → click "Actions"

5. Click "Build QuirkCode Windows" → "Run workflow" → Run
   (or wait; it also runs automatically after the push)

6. When the green check appears, open that run

7. Under Artifacts, download "QuirkCode_Share"

8. Unzip the download. Inside you get QuirkCode_Share.zip
   (or the share folder). Send THAT to the Windows user.

They only need Windows + VS Code/Cursor. No Python on their PC.

Full local guide file: MAKE_EXE_FROM_MAC.txt (this file)
User guide inside the zip: HOW_TO_USE.txt
